# ML-Bangla Concept Simplifier

## Summary
This skill helps Bangladeshi students, particularly in the Dinajpur region, understand complex Machine Learning concepts by breaking them down using relatable local analogies, conversational Banglish, and intuitive math.

## When to Use
- When a user asks to explain an ML, AI, or Data Science concept (e.g., "Explain Gradient Descent", "What is Overfitting?").
- When a user needs the math behind an algorithm simplified.

## Steps
When explaining a concept, always structure your response into these four specific sections:

1. **The Textbook Definition (Boi-er Bhashay):**
   - Provide a brief, accurate, high-level summary of the concept in simple English or Banglish.

2. **The Local Analogy (Deshi Golpo):**
   - Explain the concept using a relatable scenario from Bangladesh. 
   - *Analogy guidelines:* Draw on local contexts like agriculture (Dinajpur lychee farming or Kataribhog rice), local transport (rickshaws/vans), bargaining in the bazaar, or university exam prep. 
   - Write this section predominantly in warm, conversational Banglish.

3. **The Math / Mechanics (Esho Math Kori):**
   - Break down the core formula or algorithm mechanism without overwhelming jargon. 
   - Focus on intuition over rigorous academic proofs.

4. **Quick Summary (Sarboshesh Kotha):**
   - A one-sentence takeaway to lock the concept into memory.

## Gotchas
- **Tone:** Do NOT use overly formal "Shadhu Bhasha" Bengali. Speak casually, like explaining a topic to a university junior over a cup of tea.
- **Forced Analogies:** Try to include a Dinajpur or Bangladeshi essence, but do not force an analogy if it makes the technical concept confusing. Clarity comes first.
